AmberVentory {{ .Chart.AppVersion }} установлен как релиз "{{ .Release.Name }}" в пространстве имён "{{ .Release.Namespace }}".

1. Откройте веб-интерфейс:
{{- if .Values.ingress.enabled }}
{{- range $host := .Values.ingress.hosts }}
  http{{ if $.Values.ingress.tls }}s{{ end }}://{{ $host.host }}
{{- end }}
{{- else if .Values.httpRoute.enabled }}
  {{- range .Values.httpRoute.hostnames }}
  https://{{ . }}   (схему уточните по listener Gateway)
  {{- end }}
{{- else if eq .Values.service.type "NodePort" }}
  export NODE_PORT=$(kubectl get svc -n {{ .Release.Namespace }} {{ include "amberventory.fullname" . }} -o jsonpath="{.spec.ports[0].nodePort}")
  export NODE_IP=$(kubectl get nodes -o jsonpath="{.items[0].status.addresses[0].address}")
  echo http://$NODE_IP:$NODE_PORT
{{- else if eq .Values.service.type "LoadBalancer" }}
  kubectl get svc -n {{ .Release.Namespace }} {{ include "amberventory.fullname" . }} -w   # дождитесь EXTERNAL-IP
{{- else }}
  kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "amberventory.fullname" . }} 8080:{{ .Values.service.port }}
  затем откройте http://127.0.0.1:8080
{{- end }}
{{- if .Values.auth.enabled }}

2. Войдите (HTTP basic auth):
{{- if .Values.auth.existingSecret }}
  пользователь: kubectl get secret -n {{ .Release.Namespace }} {{ .Values.auth.existingSecret }} -o jsonpath="{.data.{{ .Values.auth.existingSecretUserKey }}}" | base64 -d; echo
  пароль:       kubectl get secret -n {{ .Release.Namespace }} {{ .Values.auth.existingSecret }} -o jsonpath="{.data.{{ .Values.auth.existingSecretPasswordKey }}}" | base64 -d; echo
{{- else }}
  пользователь: {{ .Values.auth.username }}
  пароль:       kubectl get secret -n {{ .Release.Namespace }} {{ include "amberventory.fullname" . }} -o jsonpath="{.data.password}" | base64 -d; echo
{{- end }}
{{- else }}

ВНИМАНИЕ: auth.enabled = false. Любой, кто может обратиться к Service, может сканировать
вашу сеть и использовать сохранённый SSH-ключ. Включите аутентификацию или ограничьте доступ NetworkPolicy.
{{- end }}

Дальше: дождитесь загрузки баз уязвимостей (сервис загружает их при первом запуске),
загрузите SSH-ключ, затем просканируйте подсеть или загрузите inventory.
{{- if not .Values.persistence.enabled }}

ВНИМАНИЕ: persistence.enabled = false. SSH-ключ, отчёты и базы уязвимостей
теряются при каждом перезапуске пода.
{{- end }}
{{- if .Values.hostNetwork }}

Обратите внимание: hostNetwork включён. Сервис слушает порт {{ .Values.config.port }} на узле, где запущен под.
{{- end }}

Проверка установки: helm test {{ .Release.Name }} -n {{ .Release.Namespace }}
