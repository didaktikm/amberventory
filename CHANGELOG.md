## [0.2.0] — 2026-10-27

### Изменено

- Логотип и палитра по фирменному стилю Amber Data: оранжевый `#E75001` в логотипе, баннере, интерфейсе и отчётах; знак повторяет форму камня-янтаря.
- Документация переработана: README — обзор и быстрый старт, подробности в `docs/` (требования, развёртывание, настройка, эксплуатация, безопасность, оценка уязвимостей, устранение неполадок, словарь). Документация и `NOTES` чарта переведены на русский.
- Quick Start через `docker run` с файлом `--env-file`; Compose читает настройки из `.env` и использует том `amberventory-data`.
- Пункт «Запускать сборщик целиком через sudo» в интерфейсе: подсказка уточнена, описаны оба режима прав.
- Helm: описания параметров и `NOTES` переведены на русский; версия Chart.yaml берётся из тега.

### Исправлено

- CI: `ct lint` получил схему `Chart.yaml` и конфиг yamllint; `yamale`/`yamllint` ставятся через `setup-python`; helm-docs зафиксирован на версии 1.14.2.
- Публикация образа: убран запрос `security-events` и шаг Trivy, из-за которых джоб падал на этапе подготовки.
- Документация: исправлены утверждения о сборщике (временная копия скрипта на хосте), о шкале уровней, о Trivy и о томах Compose.

### Известные проблемы

- Импорт EPSS не проверяет целостность скачанного файла: при обрыве загрузки базы не обновляются полностью (см. `docs/troubleshooting.md`).
- В варианте `docker run` с bridge-сетью нужен `AMBER_HOST=0.0.0.0`; в Docker Desktop без host-сети используйте `-p 127.0.0.1:8080:8080` с этим флагом.
- Видимость пакетов GHCR меняется вручную (REST API не поддерживает).

## [0.1.0] — 2026-10-27

Первый выпуск.

### Добавлено

- Поиск хостов сканированием подсети (nmap) и импорт inventory Ansible в форматах INI и YAML.
- Сбор сведений о хостах без агентов: релиз и срок поддержки Debian, ядра, файловые системы, пользователи, прикладные службы, открытые порты, параметры `sshd`, TLS-сертификаты, пакеты и доступные обновления.
- Оценка уязвимостей по Debian Security Tracker с учётом CISA KEV, FIRST EPSS и CVSS из NVD; список наблюдения.
- Отчёты: сводка по парку, детализация по хостам, CVE и службам; история; выгрузка в CSV и JSON.
- Работа в изолированном контуре: внутренние зеркала и ручная загрузка трекера Debian.
- Образ для `linux/amd64` и `linux/arm64`, Docker Compose, Helm-чарт.
- CI: тесты, линтеры, проверка чарта, e2e-установка в kind; публикация образа и чарта в GHCR.
