# Термины

Термины, которые используются в документации и интерфейсе. Используйте их без синонимов.

| Термин | Значение | Не используем |
|---|---|---|
| Хост | сервер, сведения о котором собирает сервис | цель, машина, нода |
| Парк | все хосты, охваченные отчётом | флот, инфраструктура |
| Сервис | развёрнутый экземпляр AmberVentory | приложение, система |
| Сборщик | скрипт `ansible/collector.sh`, выполняемый на хосте | агент, коллектор |
| Сбор | однократный запуск сборщика на выбранных хостах; в API — задание (`/api/jobs`) | скан, задача, джоба |
| Сканирование | поиск хостов в подсети с помощью nmap | сбор |
| Inventory | файл Ansible со списком хостов | инвентарь |
| Отчёт | результат сбора с оценкой уязвимостей | репорт |
| Находка | одна CVE для одного пакета на одном хосте; также проблема конфигурации | уязвимость (когда речь о конкретной записи отчёта) |
| Уровень | критичность находки: «Критично», «Высокий», «Средний», «Низкий», «Без оценки», «Несущественно» | severity, серьёзность |
| Статус | состояние исправления находки: «Есть исправление», «Исправления нет» и др. | — |
| Базы уязвимостей | данные Debian Security Tracker, CISA KEV, FIRST EPSS и NVD, загруженные в сервис | фиды, источники (как синоним) |
| Список наблюдения | пакеты, которые подсвечиваются в отчёте независимо от находок (`AMBER_WATCHLIST`) | вотчлист |
| Изолированный контур | установка без доступа в интернет | air-gap, офлайн |
